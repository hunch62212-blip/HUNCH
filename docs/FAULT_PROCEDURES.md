# AEGIS-V1 failure catalogue and procedures

Generated by `node scripts/fault_procedures.mjs` from `src/sim/health.js`. Do not edit by hand.

24 failure modes on 20 replaceable units. All MTBFs are **[ASSUMED]** engineering estimates.
Summed over every unit the rover would see a failure every ~851 h of operation; the simulator's
random-failure switch multiplies that rate (`failures on demo` = 20000x, one every ~2.6 min of sim time).

Severity: **caution** = no mission impact, fix at the next stop; **warning** = degraded (derate or redundancy lost);
**critical** = the rover stops or safes itself. Effect: **physics** = the simulator changes the vehicle model;
**annunciation** = only the sensor channel and the alarm are modelled.

## Failure modes

### `fault mc <1|2|3|4|5|6>` - Hub motor controller dropout

* **Severity / effect:** warning / physics. MTBF 60,000 h per unit.
* **Cause:** inverter gate-driver latch-up or DC-link capacitor failure.
* **Unit and location:** MC (Hub motor controller drawer (3-phase inverter, resolver interface, brake driver)); Bay MC-L - port motor controllers, port tub wall, in the gap between the front and middle wheels.
* **Sensors:** CAN heartbeat from MC-n (50 Hz); phase current sensor; wheel resolver.
* **Detection rule:** heartbeat missing for 0.3 s with the bus up.
* **Automatic response:** drive inhibit on wheel n (free-rolls), torque re-allocated to the other 5 wheels, autonomy speed derated 25 %.
* **Operator:** Continue the mission derated; avoid slopes > 12 deg loaded.
* **Operator:** Swap the MC drawer at the next stop (field, 15 min, kit spare).
* **Repair** (field, 15 min, `repair mc <unit>`):
  1. Park on < 5 deg slope, set spring brakes, autonomy hold
  2. Kneel (ride -0.65 m): the bays drop to working height
  3. Open the bay door: interlock opens its solid-state breaker; check 0 V at the bay test point
  4. Pull the drawer by its handle (4 quarter-turn fasteners)
  5. Slide in the spare (blind-mate power + CAN)
  6. Spin the wheel 1 rev off load: resolver and phase currents
  7. Close the door (interlock re-arms the breaker)
  8. Run the unit built-in test (BIT) and a 10 s functional check; confirm the alarm clears

### `fault seize <1|2|3|4|5|6>` - Wheel-end seized (gearbox / bearing / brake fails to release)

* **Severity / effect:** warning / physics. MTBF 150,000 h per unit.
* **Cause:** regolith past the hub seal, gearbox bearing failure, or spring brake stuck applied.
* **Unit and location:** WHL (Wheel-end assembly (hub motor, planetary gearbox, spring brake, resolver, declutch)); Wheel end, hub of each wheel (motor, gearbox, spring brake, resolver, declutch).
* **Sensors:** phase current sensor; wheel resolver; hub thermistor; brake solenoid current.
* **Detection rule:** phase current at the limit while the resolver shows < 0.05 rad/s and the wheel is commanded > 0.3 rad/s, for 1.5 s.
* **Automatic response:** stop, retract the declutch pin so the wheel free-rolls (LRV / Lunokhod heritage), continue on 5 driven wheels derated 25 %.
* **Operator:** Confirm the declutch with a 1 m creep (wheel turns freely).
* **Operator:** Wheel-end swap at the dock (90 min, gantry).
* **Repair** (dock, 90 min, `repair seize <unit>`):
  1. Park on < 5 deg slope, set spring brakes, autonomy hold
  2. Kneel (ride -0.65 m): the bays drop to working height
  3. Open the bay door: interlock opens its solid-state breaker; check 0 V at the bay test point
  4. Drive onto the dock service pad
  5. Strut lifts the corner (3-legged stance on the other five)
  6. Gantry hoist takes the wheel; remove 12 hub bolts and the harness connector
  7. Fit spare wheel end, torque bolts, reconnect
  8. Lower corner, re-engage declutch, brake release test
  9. Close the door (interlock re-arms the breaker)
  10. Run the unit built-in test (BIT) and a 10 s functional check; confirm the alarm clears

### `fault enc <1|2|3|4|5|6>` - Wheel resolver failure

* **Severity / effect:** caution / annunciation. MTBF 100,000 h per unit.
* **Cause:** resolver winding open or connector fretting.
* **Unit and location:** ENC (Wheel resolver cartridge); Wheel end, hub of each wheel (motor, gearbox, spring brake, resolver, declutch).
* **Sensors:** wheel resolver; back-EMF speed estimate from the motor controller.
* **Detection rule:** resolver reads 0 while back-EMF speed > 0.5 rad/s, for 1 s (latent while parked).

### `fault strut <1|2|3|4|5|6>` - Roller-screw actuator jam / motor winding open circuit

* **Severity / effect:** caution / annunciation. MTBF 70,000 h per unit.
* **Cause:** regolith past the bellows into the roller screw (jam), or an open servo winding / connector (CHANGES.md §17).
* **Unit and location:** STRUT (Roller-screw strut actuator (BLDC servo + metal bellows)); Wheel end, hub of each wheel (motor, gearbox, spring brake, resolver, declutch).
* **Sensors:** servo phase-current sensor; actuator LVDT (stroke); screw resolver.
* **Detection rule:** actuator force response < 85 % of the value the load model expects, for 5 s.
* **Automatic response:** servo drive derates the corner, screw brake held between levelling moves, speed derated 15 %.
* **Operator:** If the response keeps falling below 65 %, kneel is inhibited: finish the leg and go to the dock.
* **Operator:** Actuator cartridge swap at the dock (60 min).
* **Repair** (dock, 60 min, `repair strut <unit>`):
  1. Park on < 5 deg slope, set spring brakes, autonomy hold
  2. Kneel (ride -0.65 m): the bays drop to working height
  3. Open the bay door: interlock opens its solid-state breaker; check 0 V at the bay test point
  4. Drive onto the dock service pad, gantry takes the corner weight
  5. Safe the servo drive, set the screw brake
  6. Swap the actuator cartridge (roller screw, servo, bellows) and the power harness
  7. Re-home the screw to its end stop, levelling self-calibration
  8. Close the door (interlock re-arms the breaker)
  9. Run the unit built-in test (BIT) and a 10 s functional check; confirm the alarm clears

### `fault bat <1|2|3|4>` - Battery string fault (cell short / BMS trip)
