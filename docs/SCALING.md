# Scaling sheet: prototype (Earth bench, 1:8.16) to full scale (Moon)

Generated by `node scripts/scaling_sheet.mjs` from `src/sim/scaling.js` and `src/sim/config.js`. Do not edit by hand.

The prototype is a geometric 1:K model (K = 8.16) tested in Earth gravity (9.80665 m/s²). The rover is meant for lunar gravity (1.62 m/s²).
gR = g_moon / g_earth = **0.1652**. Dynamic quantities scale by Froude similarity (v² / g L equal at both scales), so gravity enters every row below.
Before the review pass (item 6) the code divided wheel rpm by √K only, which holds only if gravity is the same at both scales.

## What does not scale this way

* **Batteries, solar arrays, radiators and chargers are sized for the full-scale job.** The bench 128 Wh pack and 126 W array are not multiplied up.
  The earlier dock model did that (× 1172) and implied a 148 kW array and a 2.8 MWh bank.
* **Thermal:** radiated power goes as area (K²) and σT⁴, not gR. A bench radiator does not predict full-scale heat rejection.
* **Soil:** Bekker sinkage uses pressure (K gR) but regolith particles do not scale. Bench tests on sand do not validate the full-scale terramechanics.
* **Electronics, sensors and control rates:** unchanged. Controllers tuned on the bench need re-tuning for the time ratio √(K / gR) = 7.03.
